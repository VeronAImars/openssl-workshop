# Code of Conduct

OpenSSL Workshop has adopted the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(version 2.1) as its Code of Conduct. All participants, contributors, maintainers and users, are
expected to abide by it.

## Reporting

Report unacceptable behaviour to the maintainer **[@veronaimars](https://github.com/veronaimars)**
on GitHub. Reports are handled confidentially.
