# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report privately, in order of preference:

1. **GitHub private security advisories**: open the repository's **Security** tab and choose
   **Report a vulnerability**. Private, supports coordinated disclosure, can issue a CVE.
2. **Direct contact**: message the maintainer **[@veronaimars](https://github.com/veronaimars)** on GitHub.

You will get an acknowledgement within seven days. Please give a reasonable time to fix before
public disclosure.

## Supported versions

The latest release and `main`.
