# DR-001 — Independent, clean-room, open source

**Date:** 2026-11-07. **Status:** decided. **Maintainer:** veronaimars.

## Question

Who owns this project, what may it draw on, and how is it funded?

## Context

- The project starts from zero. No earlier code is carried forward.
- The maintainer works elsewhere; nothing from that work may enter this repository.

## Decision

- One maintainer, veronaimars. Contributions arrive through pull requests like anyone's.
- Clean-room: everything here is written here, from public sources with a URL per claim.
  No code, data or infrastructure from any employer or other organisation.
- Open source under Apache-2.0. No paid, hosted-paid or hybrid edition. Free public hosting of a site or sandbox is fine.
- Any in-kind hosting is disclosed on the project page and runs under accounts and a domain the
  project owns, so it can move.

## Consequences

- No partner, sponsor or employer is named in this repository.
- Funding, if any, is grants or donations to the maintainer, recorded in a later DR.
